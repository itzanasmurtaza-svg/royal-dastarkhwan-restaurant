🍽️ Royal Dastarkhwan
A Royal Taste of Pakistan 🇵🇰

Royal Dastarkhwan is a premium Pakistani restaurant website designed to deliver an elegant, modern, and immersive digital dining experience.

The website combines luxury visual design, responsive layouts, smooth animations, and an authentic Pakistani restaurant identity to create a professional online presence.

✨ Features
🏛️ Premium luxury restaurant design
🍛 Pakistani & traditional cuisine showcase
📋 Interactive food menu
📱 Fully responsive design
✨ Smooth animations & transitions
🖼️ High-quality food imagery
📍 Restaurant location section
📞 Contact & reservation section
⭐ Customer testimonials
🎨 Modern typography & elegant color palette
⚡ Fast and lightweight frontend
💻 Mobile, tablet & desktop support
🛠️ Technologies Used
HTML5 — Website structure
CSS3 — Styling, animations & responsive design
JavaScript — Interactive functionality
